This is a website using only html and bootstrap.
I used Bootstrap utilities to create buttons, and one that disappears on smaller devices.
I created a nav bar that sticks to the top of the screen at all times and does the hamburger image on small devices.
I added a table displaying user data that is responsive, allowing for horizontal scrolling on smaller devices.
I also added a form that has required email and password.
There is also 2 images, one that is circular and one that stretches the entire screen.
Images were used from Stockcake.com for free.
